# Демо-концепты сайтов автосервисов Пскова

Это **демо-концепты**, а не официальные сайты компаний. Страницы сделаны как пример оформления по открытым данным из публичных карточек; компании их не заказывали и не утверждали. **Удалим любую страницу по первой просьбе** — напишите владельцу репозитория.

Все страницы закрыты от индексации (`meta robots noindex, nofollow`, `robots.txt` с `Disallow: /`).

## Как открыть

- Локально: скачайте папку целиком и откройте `index.html` в браузере — это каталог из 23 страниц.
- Через GitHub Pages: включите Pages для ветки с этими файлами (корень репозитория); `.nojekyll` уже лежит в корне.

Структура: `<название-компании>/index.html` — страницы (например, `transservice/`, `konstanta/`), `ui/` — стили и скрипты, `assets/` — фото. Карта на страницах загружается из OpenStreetMap через интернет.
